## Possible production issues noticed (not fixed)
- `GrpcTenantAccessPolicy.hasPremium` and the AI usage handler run outside a Spring transaction (J3 deviation 5); only basic columns are read so lazy loading should be fine, but `consumeAiQuestion` for a tenant without a `tenants` row would be an `INTERNAL`, not a denial (cannot happen after the allowlist check).
