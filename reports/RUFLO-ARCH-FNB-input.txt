# Architecture snapshot

Reviewed: 2026-10-07 (Asia/Jakarta). Memory version: 2.
Evidence: current working-tree source, pom.xml, AGENTS.md, PRD-MVP.md, and Codebase Memory graph. This is a structural review, not runtime or security certification.

## Application structure

One Java 17 / Spring Boot 4.1.1 backend: a modular monolith organized in existing top-level packages under `org.lite.project.cashiersaas`.

```mermaid
flowchart LR
    HTTP[Staff or public HTTP client] --> Security[Spring Security / JWT]
    Security --> Controller[controller]
    Controller --> Service[service: use cases and transactions]
    Service --> Guard[MerchantAccessGuard]
    Service --> Repository[repository: JPA / Blaze-Persistence]
    Repository --> DB[(PostgreSQL)]
    Service --> Mapper[dto: explicit mappers]
    Mapper --> Response[ApiResponse and named DTOs]
```

Controllers adapt HTTP and return `ApiResponse<T>`; services coordinate transactions, guards, persistence and explicit DTO mappers. Entities own named business transitions. Repositories use EntityManager and Blaze-Persistence; QueryDSL generated Q types support typed paths. `ApiResponse` omits null fields. Current exception classes reside in `exception/runtime`, with `GlobalExceptionHandler`; AGENTS.md instead prescribes `shared/exception/runtime` for the policy boundary. Do not silently move existing code during discovery.

## Functional boundaries

- Identity and sessions: RegisterService, LoginService, AuthSessionService, JwtTokenService, JWT configuration and conversion. Account scope supports onboarding and merchant selection; merchant scope carries tenant/outlet/membership context. Refresh tokens are persisted as digests and rotated; sessions support revocation. Stateless HTTP security does not mean refresh sessions have no database state.
- Merchant foundation: tenant, outlet, tenant membership, membership outlet access, invitations, onboarding and subscription/free-tier services.
- F&B catalog and QR: FnbCatalogService, FnbTableService, FnbOrderQrService, PublicQrAccessService. Public QR resolves tenant/outlet and optional table from validated server-side token context.
- Shared F&B checkout: PublicOrderService and FnbPosOrderService use FnbOrderPricingService and SalesOrderEntity with line/option snapshots. Both sources feed the same operational order model.
- Operations: FnbStaffOrderService, FnbDiscountService, FnbOrderCancellationService, FnbPaymentService, MockFnbGatewayService, FnbKitchenService and FnbTableReconciliationService.
- Receipts and reports: FnbReceiptService and FnbSalesReportService/FnbSalesReportRepository. Paid-sales queries scope both payment and order to tenant/outlet, use payment time, require PAID and exclude CANCELLED.
- Separate earlier cashier sales/catalog services and broader laundry/inventory/platform entity/schema areas remain present. Their existence does not establish active MVP acceptance or completed features.

## Security and tenancy

SecurityConfiguration owns stateless HTTP policy, BCrypt and CORS. JwtConfiguration wires HS256 signing/verification, mandatory environment secret, issuer/audience/time and required claims checks. TenantJwtAuthenticationConverter distinguishes ACCOUNT and MERCHANT scopes. Merchant conversion requires UUID subject, session, tenant, outlet and membership claims plus supported roles.

Active role policy is exactly SUPERADMIN, OWNERMERCHANT and CASHIER. Platform routes require SUPERADMIN; merchant routes OWNERMERCHANT; cashier routes OWNERMERCHANT or CASHIER. Account-only routes use SCOPE_ACCOUNT. Public QR routes are anonymous and use token-scoped context.

MerchantAccessGuard checks principal outlet and reloads authorized membership/outlet access through MerchantAccessRepository. Failed ownership/access checks use ResourceNotFoundException to avoid disclosing another tenant's records. Protected data context comes from the principal, public context from validated QR. This review sampled boundaries; exhaustive tenant-isolation proof remains pending.

## Pay First state and consistency

```text
QR/POS checkout -> NEW + UNPAID
successful settlement -> CONFIRMED + PAID
kitchen -> PREPARING -> READY -> COMPLETED
NEW + UNPAID -> CANCELLED (reason and audit in service)
```

SalesOrderEntity enforces these transitions. Discount and cancellation require NEW/UNPAID. Pricing uses BigDecimal, server-side availability/pricing and order snapshots. Checkout requires an idempotency key and stores a request fingerprint; changed-request key reuse conflicts. Payment supports replay/conflict checks and a separate mock gateway attempt model. Payment settlement records payment, audit and table reconciliation inside the service transaction.

FnbOrderRepository locks the tenant row with PESSIMISTIC_WRITE. Checkout/payment/kitchen use this coordination; it serializes mutations for a tenant and is a potential throughput bottleneck. Entity uniqueness includes tenant/idempotency and outlet/order-number. Runtime concurrency and actual database constraint enforcement were not tested.

import lombok.RequiredArgsConstructor;

@Service
@RequiredArgsConstructor
public class PublicOrderService {
    private static final Duration TOKEN_TTL = Duration.ofDays(30);
    private final PublicQrAccessService publicQrAccess;
    private final FnbOrderRepository orders;
    private final PublicOrderTokenService tokens;
    private final FnbOrderPricingService pricing;

    @Transactional
    public PublicOrderResponse checkout(String qrToken, String key, PublicOrderRequest request) {
        if (key == null || !key.matches("[A-Za-z0-9_-]{16,128}"))
            throw new InvalidOperationException("Idempotency-Key wajib 16-128 karakter alfanumerik, '_' atau '-'.");
        TableQrTokenEntity qr = publicQrAccess.requirePublicQr(qrToken);
        UUID tenantId = qr.getTenant().getId();
        UUID outletId = qr.getOutlet().getId();
        UUID tableId = qr.getDiningTable() == null ? null : qr.getDiningTable().getId();
        if (tableId != null && request.getServiceType() != org.lite.project.cashiersaas.enums.ServiceType.DINE_IN)
            throw new InvalidOperationException("QR meja hanya untuk dine-in.");
        String fingerprint = fingerprint(tableId, request);
        orders.lockTenant(tenantId);
        orders.refreshQr(qr);
        // Rotation invalidates the old QR immediately, including in-flight requests queued on the tenant lock.
        if (!qr.isActive() || !qr.getToken().equals(qrToken) || (qr.getDiningTable() != null && !qr.getDiningTable().isActive())
                || !qr.getOutlet().isActive() || !qr.getTenant().isActive()) throw new ResourceNotFoundException();
        publicQrAccess.requirePublicQr(qrToken);
        String statusToken = tokens.token(tenantId, key);
        var existing = orders.byIdempotency(tenantId, key);
        if (existing.isPresent()) {
            if (!existing.get().getOutlet().getId().equals(outletId))
                throw new OperationConflictException("Idempotency-Key telah digunakan.");
            return existingOrder(existing.get(), tableId, fingerprint, statusToken);
        }
        FnbOrderPricingService.PricedOrder priced = pricing.price(tenantId, outletId,
                request.getItems().stream().map(item -> new FnbOrderPricingService.LineInput(item.getProductId(),
                        item.getQuantity(), item.getNote(), item.getOptionIds())).toList(),
                qr.getTenant().getTaxRate(), qr.getTenant().getServiceChargeRate());
        String number = "QR-" + UUID.randomUUID().toString().replace("-", "").substring(0, 20).toUpperCase();
        SalesOrderEntity order = SalesOrderEntity.publicQr(qr.getTenant(), qr.getOutlet(),
                new SalesOrderEntity.PublicQrDetails(qr.getDiningTable(), key, fingerprint, number,
                        tokens.digest(statusToken), Instant.now().plus(TOKEN_TTL), request.getCustomerLabel().trim()),
                new SalesOrderEntity.Charges(priced.subtotal(), priced.taxAmount(), priced.serviceChargeAmount()));
        order.snapshotRates(qr.getTenant().getTaxRate(), qr.getTenant().getServiceChargeRate());
        order.selectPublicServiceType(request.getServiceType());
        orders.persist(order);
        persistLines(qr, order, priced.lines());
        if (qr.getDiningTable() != null) qr.getDiningTable().markAwaitingPayment();
        orders.flush();
        return FnbOrderMapper.publicOrder(order, statusToken);
    }

    private PublicOrderResponse existingOrder(SalesOrderEntity previous, UUID tableId, String fingerprint,
                                              String statusToken) {
        if (!fingerprint.equals(previous.getRequestFingerprint()) || previous.getSource() != OrderSource.QR
                || !java.util.Objects.equals(tableId, previous.getDiningTable() == null ? null : previous.getDiningTable().getId()))
            throw new OperationConflictException("Idempotency-Key telah digunakan untuk pesanan berbeda.");
        if (previous.getPublicStatusTokenExpiresAt().isBefore(Instant.now()))
            throw new OperationConflictException("Token status pesanan telah kedaluwarsa.");
        if (!tokens.digest(statusToken).equals(previous.getPublicStatusTokenDigest()))
            throw new OperationConflictException("Token status tidak lagi dapat direkonstruksi.");
        return FnbOrderMapper.publicOrder(previous, statusToken);
    }

    private void persistLines(TableQrTokenEntity qr, SalesOrderEntity order, List<FnbOrderPricingService.PricedLine> lines) {
        for (FnbOrderPricingService.PricedLine line : lines) {
            OrderItemEntity saved = OrderItemEntity.snapshot(qr.getTenant(), qr.getOutlet(), order,
                    line.product(), line.input().quantity(), line.lineTotal(), line.input().note());
            orders.persist(saved);
            for (ProductOptionEntity option : line.options())
                orders.persist(OrderItemOptionEntity.snapshot(qr.getTenant(), qr.getOutlet(), saved, option));
        }
    }

    @Transactional(readOnly = true)
    public PublicOrderResponse status(String token) {
        if (token == null || !token.matches("[A-Za-z0-9_-]{43}")) throw new ResourceNotFoundException();
        SalesOrderEntity order = orders.byStatusDigest(tokens.digest(token)).orElseThrow(ResourceNotFoundException::new);
        if (order.getPublicStatusTokenExpiresAt() == null || !order.getPublicStatusTokenExpiresAt().isAfter(Instant.now()))
            throw new ResourceNotFoundException();
        return FnbOrderMapper.publicOrder(order, null);
    }

    private String fingerprint(UUID tableId, PublicOrderRequest request) {
        try {
            ByteArrayOutputStream bytes = new ByteArrayOutputStream();
            DataOutputStream out = new DataOutputStream(bytes);
            out.writeUTF(tableId == null ? "OUTLET:" + request.getServiceType().name() : tableId.toString());
            out.writeUTF(request.getCustomerLabel().trim());
            out.writeInt(request.getItems().size());
            for (PublicOrderRequest.Item item : request.getItems()) {
                out.writeUTF(item.getProductId().toString());
                out.writeInt(item.getQuantity());
                out.writeUTF(item.getNote() == null ? "" : item.getNote());
                List<UUID> ids = item.getOptionIds().stream().sorted(Comparator.naturalOrder()).toList();
                out.writeInt(ids.size());
                for (UUID id : ids) out.writeUTF(id.toString());
            }
            out.flush();
            return HexFormat.of().formatHex(MessageDigest.getInstance("SHA-256").digest(bytes.toByteArray()));
        } catch (IOException | NoSuchAlgorithmException exception) {
            throw new IllegalStateException("Cannot fingerprint checkout", exception);
        }
    }
}

package org.lite.project.cashiersaas.service;

import lombok.RequiredArgsConstructor;
import org.lite.project.cashiersaas.component.MerchantAccessContext;
import org.lite.project.cashiersaas.component.TenantPrincipal;
import org.lite.project.cashiersaas.dto.FnbStaffOrderMapper;

import org.lite.project.cashiersaas.dto.response.FnbStaffOrderResponse;
import org.lite.project.cashiersaas.entity.fnb.DiningTableEntity;
import org.lite.project.cashiersaas.entity.fnb.OrderItemEntity;
import org.lite.project.cashiersaas.entity.fnb.OrderItemOptionEntity;
import org.lite.project.cashiersaas.entity.fnb.ProductOptionEntity;

import org.springframework.stereotype.Service;

import java.nio.charset.StandardCharsets;

import java.security.NoSuchAlgorithmException;
import java.util.Comparator;

@Service
@RequiredArgsConstructor
public class FnbPosOrderService {
    private final MerchantAccessGuard guard;
    private final FnbTableRepository tables;
    private final FnbOrderRepository orders;
    private final FnbOrderPricingService pricing;

    @Transactional
    public FnbStaffOrderResponse checkout(TenantPrincipal principal, UUID outletId, String key,
                                          FnbPosOrderRequest request) {
        MerchantAccessContext context = guard.requireOutlet(principal, outletId);
        String idempotencyKey = validatedKey(key);
        String fingerprint = fingerprint(request);
        orders.lockTenant(context.getTenant().getId());
        context = guard.requireOutlet(principal, outletId);
        if (!context.getTenant().isActive() || !context.getTenant().isFnbEnabled() || !context.getOutlet().isActive())
            throw new ResourceNotFoundException();
        DiningTableEntity table = selectedTable(context, request);
        SalesOrderEntity existing = orders.byIdempotency(context.getTenant().getId(), idempotencyKey).orElse(null);
        if (existing != null) return replay(existing, outletId, fingerprint);
        FnbOrderPricingService.PricedOrder priced = pricing.price(context.getTenant().getId(), outletId,
                request.getItems().stream().map(item -> new FnbOrderPricingService.LineInput(item.getProductId(),
                        item.getQuantity(), item.getNote(), item.getOptionIds())).toList(),
                context.getTenant().getTaxRate(), context.getTenant().getServiceChargeRate());
        String number = "POS-" + UUID.randomUUID().toString().replace("-", "").substring(0, 20).toUpperCase();
        SalesOrderEntity order = SalesOrderEntity.pos(context.getTenant(), context.getOutlet(),
                new SalesOrderEntity.PosDetails(table, idempotencyKey, fingerprint, number,
                        request.getServiceType(), request.getCustomerLabel().trim()),
                new SalesOrderEntity.Charges(priced.subtotal(), priced.taxAmount(), priced.serviceChargeAmount()));
        order.snapshotRates(context.getTenant().getTaxRate(), context.getTenant().getServiceChargeRate());
        orders.persist(order);
        persistLines(context, order, priced.lines());
        if (table != null) table.markAwaitingPayment();
        orders.flush();
        return response(order);
    }

    private DiningTableEntity selectedTable(MerchantAccessContext context, FnbPosOrderRequest request) {
        if (request.getServiceType() == null) throw new InvalidOperationException("Tipe layanan wajib diisi.");
        if (request.getServiceType() == ServiceType.TAKEAWAY) {
            if (request.getTableId() != null) throw new InvalidOperationException("Takeaway tidak dapat memakai meja.");
            return null;
        }
        if (request.getServiceType() != ServiceType.DINE_IN) throw new InvalidOperationException("Tipe layanan tidak valid.");
        if (request.getTableId() == null) return null;
        DiningTableEntity table = tables.find(context.getTenant().getId(), context.getOutlet().getId(), request.getTableId())
                .orElseThrow(ResourceNotFoundException::new);
        if (!table.isActive()) throw new InvalidOperationException("Meja tidak tersedia.");
        return table;
    }

    private FnbStaffOrderResponse replay(SalesOrderEntity existing, UUID outletId, String fingerprint) {
        if (existing.getSource() != OrderSource.POS || !existing.getOutlet().getId().equals(outletId)
                || !fingerprint.equals(existing.getRequestFingerprint())) {
            throw new OperationConflictException("Idempotency-Key telah digunakan untuk pesanan berbeda.");
        }
        return response(existing);
    }

    private void persistLines(MerchantAccessContext context, SalesOrderEntity order,
                              List<FnbOrderPricingService.PricedLine> lines) {
        for (FnbOrderPricingService.PricedLine line : lines) {
            OrderItemEntity item = OrderItemEntity.snapshot(context.getTenant(), context.getOutlet(), order,
                    line.product(), line.input().quantity(), line.lineTotal(), line.input().note());
            orders.persist(item);
            for (ProductOptionEntity option : line.options())
                orders.persist(OrderItemOptionEntity.snapshot(context.getTenant(), context.getOutlet(), item, option));
        }
    }

    private FnbStaffOrderResponse response(SalesOrderEntity order) {
        List<OrderItemEntity> items = orders.items(order.getTenant().getId(), order.getOutlet().getId(), List.of(order.getId()));
        List<UUID> itemIds = items.stream().map(OrderItemEntity::getId).toList();
        List<OrderItemOptionEntity> options = orders.itemOptions(order.getTenant().getId(), order.getOutlet().getId(), itemIds);
        return FnbStaffOrderMapper.order(order, items, options);
    }

    private String validatedKey(String key) {
        if (key == null || !key.matches("[A-Za-z0-9_-]{16,128}"))
            throw new InvalidOperationException("Idempotency-Key wajib 16-128 karakter alfanumerik, '_' atau '-'.");
        return key;
    }

    private String fingerprint(FnbPosOrderRequest request) {
        StringBuilder canonical = new StringBuilder();
        append(canonical, request.getServiceType() == null ? null : request.getServiceType().name());
        append(canonical, request.getTableId() == null ? null : request.getTableId().toString());
        append(canonical, request.getCustomerLabel() == null ? null : request.getCustomerLabel().trim());
        if (request.getItems() == null) throw new InvalidOperationException("Pesanan harus memiliki item.");
        for (FnbPosOrderRequest.Item item : request.getItems()) {
            append(canonical, item.getProductId() == null ? null : item.getProductId().toString());
            append(canonical, Integer.toString(item.getQuantity()));
            append(canonical, item.getNote());
            if (item.getOptionIds() == null) throw new InvalidOperationException("Pilihan item tidak valid.");
            List<UUID> optionIds = item.getOptionIds().stream().sorted(Comparator.naturalOrder()).toList();
            append(canonical, Integer.toString(optionIds.size()));
            for (UUID optionId : optionIds) append(canonical, optionId.toString());
        }
        try {
            return HexFormat.of().formatHex(MessageDigest.getInstance("SHA-256")
                    .digest(canonical.toString().getBytes(StandardCharsets.UTF_8)));
        } catch (NoSuchAlgorithmException exception) {
            throw new IllegalStateException("SHA-256 is unavailable.", exception);
        }
    }

    private void append(StringBuilder builder, String value) {
        String part = value == null ? "" : value;
        builder.append(part.length()).append(':').append(part);
    }
}

@Service
@RequiredArgsConstructor
public class FnbOrderPricingService {
    private final FnbCatalogRepository catalog;

    public PricedOrder price(UUID tenantId, UUID outletId, List<LineInput> inputs,
                             BigDecimal taxRate, BigDecimal serviceChargeRate) {
        if (inputs == null || inputs.isEmpty()) throw new InvalidOperationException("Pesanan harus memiliki item.");
        requireRate(taxRate, "Tarif pajak tidak valid.");
        requireRate(serviceChargeRate, "Tarif biaya layanan tidak valid.");
        List<PricedLine> lines = new ArrayList<>();
        BigDecimal subtotal = BigDecimal.ZERO;
        for (LineInput input : inputs) {
            PricedLine line = priceLine(tenantId, outletId, input);
            lines.add(line);
            subtotal = subtotal.add(line.lineTotal());
        }
        BigDecimal taxAmount = percentage(subtotal, taxRate);
        BigDecimal serviceChargeAmount = percentage(subtotal, serviceChargeRate);
        return new PricedOrder(lines, subtotal, taxAmount, serviceChargeAmount,
                subtotal.add(taxAmount).add(serviceChargeAmount));
    }

    private PricedLine priceLine(UUID tenantId, UUID outletId, LineInput input) {
        if (input == null || input.productId() == null || input.quantity() < 1 || input.optionIds() == null)
            throw new InvalidOperationException("Item pesanan tidak valid.");
        ProductEntity product = catalog.product(tenantId, outletId, input.productId())
                .orElseThrow(() -> new InvalidOperationException("Produk tidak tersedia."));
        catalog.lock(product);
        catalog.lock(product.getCategory());
        if (!product.isAvailable() || product.isArchived() || product.getCategory().isArchived())
            throw new InvalidOperationException("Produk tidak tersedia.");
        Set<UUID> selectedIds = new HashSet<>(input.optionIds());
        if (selectedIds.size() != input.optionIds().size())
            throw new InvalidOperationException("Pilihan tidak boleh berulang.");
        List<ProductOptionEntity> selected = selectedOptions(tenantId, outletId, product, selectedIds);
        if (selected.size() != selectedIds.size())
            throw new InvalidOperationException("Pilihan bukan milik produk.");
        BigDecimal unitPrice = product.getPrice();
        for (ProductOptionEntity option : selected) unitPrice = unitPrice.add(option.getPriceAdjustment());
        if (unitPrice.signum() < 0) throw new InvalidOperationException("Harga efektif item tidak valid.");
        BigDecimal lineTotal = unitPrice.multiply(BigDecimal.valueOf(input.quantity())).setScale(2, RoundingMode.HALF_UP);
        if (lineTotal.signum() < 0) throw new InvalidOperationException("Total item tidak valid.");
        return new PricedLine(input, product, selected, unitPrice, lineTotal);
    }

    private List<ProductOptionEntity> selectedOptions(UUID tenantId, UUID outletId, ProductEntity product,
                                                       Set<UUID> selectedIds) {
        List<ProductOptionEntity> selected = new ArrayList<>();
        for (OptionGroupEntity group : catalog.groups(tenantId, outletId, product.getId())) {
            catalog.lock(group);
            int selectedCount = 0;
            for (ProductOptionEntity option : catalog.options(tenantId, outletId, group.getId())) {
                if (selectedIds.contains(option.getId())) {
                    catalog.lock(option);
                    if (!option.isAvailable()) throw new InvalidOperationException("Pilihan tidak tersedia.");
                    selected.add(option);
                    selectedCount++;
                }
            }
            if (selectedCount < group.getMinimumSelections() || selectedCount > group.getMaximumSelections())
                throw new InvalidOperationException("Jumlah pilihan pada grup tidak valid.");
        }
        return selected;
    }

    private static void requireRate(BigDecimal rate, String message) {
        if (rate == null || rate.signum() < 0) throw new InvalidOperationException(message);
    }

    private static BigDecimal percentage(BigDecimal value, BigDecimal rate) {
        return value.multiply(rate).divide(new BigDecimal("100"), 2, RoundingMode.HALF_UP);
    }

    public record LineInput(UUID productId, int quantity, String note, List<UUID> optionIds) { }

    public record PricedLine(LineInput input, ProductEntity product, List<ProductOptionEntity> options,
                             BigDecimal unitPrice, BigDecimal lineTotal) { }

    public record PricedOrder(List<PricedLine> lines, BigDecimal subtotal, BigDecimal taxAmount,
                              BigDecimal serviceChargeAmount, BigDecimal total) { }
}

    @Transactional
    public FnbPaymentResponse pay(TenantPrincipal principal, UUID outletId, UUID orderId, FnbPaymentRequest request) {
        if (request.getMethod() == PaymentMethod.MOCK_GATEWAY) return mockGateway.initiate(principal, outletId, orderId, request);
        if (request.getMethod() == null) throw new InvalidOperationException("Metode pembayaran wajib diisi.");
        orders.lockTenant(principal.getTenantId());
        MerchantAccessContext context = guard.requireOutlet(principal, outletId);
        SalesOrderEntity order = current(principal, outletId, orderId);
        String fingerprint = fingerprint(request.getMethod(), request.getAmountTendered());
        PaymentEntity keyedPayment = payments.byKey(principal.getTenantId(), request.getIdempotencyKey()).orElse(null);
        FnbGatewayAttemptEntity keyedAttempt = attempts.byKey(principal.getTenantId(), request.getIdempotencyKey()).orElse(null);
        if (keyedPayment != null) return replayPayment(keyedPayment, orderId, outletId, request.getMethod(), fingerprint);
        if (keyedAttempt != null) throw new OperationConflictException("Kunci pembayaran telah digunakan.");
        if (attempts.pendingForOrder(principal.getTenantId(), outletId, orderId).isPresent()) throw new OperationConflictException("Gateway attempt masih tertunda.");
        if (payments.byOrder(principal.getTenantId(), outletId, orderId).isPresent()) throw new OperationConflictException("Pesanan sudah dibayar.");
        BigDecimal tendered = request.getAmountTendered();
        if (request.getMethod() == PaymentMethod.CASH && tendered.compareTo(order.getTotal()) < 0) throw new InvalidOperationException("Uang tunai kurang dari total pesanan.");
        if (request.getMethod() != PaymentMethod.CASH && tendered.compareTo(order.getTotal()) != 0) throw new InvalidOperationException("Pembayaran non-tunai harus sesuai total pesanan.");
        return settle(context, order, request.getMethod(), tendered, request.getIdempotencyKey(), fingerprint, null);
    }

    FnbPaymentResponse settle(MerchantAccessContext context, SalesOrderEntity order, PaymentMethod method, BigDecimal tendered, String key, String fingerprint, String reference) {
        BigDecimal change = method == PaymentMethod.CASH ? tendered.subtract(order.getTotal()) : BigDecimal.ZERO;
        order.confirmPaid();
        PaymentEntity payment = PaymentEntity.settle(context.getTenant(), context.getOutlet(), order, method, tendered, change, receiptNumber(), key, fingerprint, reference, context.getMembership().getUser());
        payments.persist(payment); orders.flush();
        audit.persist(AuditLogEntity.recordAction(context.getTenant(), context.getOutlet(), context.getMembership().getUser(), AuditLogEntity.Action.FNB_PAYMENT_RECORDED, order.getId(), null, "method=" + method + ";paymentId=" + payment.getId()));
        reconciliation.reconcile(order);
        return FnbPaymentMapper.payment(payment);
    }

    SalesOrderEntity current(TenantPrincipal principal, UUID outletId, UUID orderId) {
        SalesOrderEntity order = orders.byId(principal.getTenantId(), outletId, orderId).orElseThrow(ResourceNotFoundException::new);
        orders.refreshOrder(order);
        return orders.byId(principal.getTenantId(), outletId, orderId).orElseThrow(ResourceNotFoundException::new);
    }

    static String fingerprint(PaymentMethod method, BigDecimal tendered) {
        String source = method.name() + "|" + normalize(tendered);
        try { return HexFormat.of().formatHex(MessageDigest.getInstance("SHA-256").digest(source.getBytes(StandardCharsets.UTF_8))); }
        catch (NoSuchAlgorithmException exception) { throw new IllegalStateException(exception); }
    }

    private FnbPaymentResponse replayPayment(PaymentEntity payment, UUID orderId, UUID outletId, PaymentMethod method, String fingerprint) {
        if (!payment.getOutlet().getId().equals(outletId) || !payment.getSalesOrder().getId().equals(orderId) || payment.getMethod() != method || !payment.getRequestFingerprint().equals(fingerprint)) throw new OperationConflictException("Kunci pembayaran telah digunakan.");
        return FnbPaymentMapper.payment(payment);
    }
    private static String normalize(BigDecimal value) { return value.stripTrailingZeros().toPlainString(); }
    private static String receiptNumber() { return "R-" + UUID.randomUUID().toString().replace("-", "").substring(0, 20).toUpperCase(); }
}

    private FnbKitchenOrderResponse transition(TenantPrincipal principal, UUID outletId, UUID orderId,
                                               String targetStatus) {
        orders.lockTenant(principal.getTenantId());
        MerchantAccessContext context = guard.requireOutlet(principal, outletId);
        SalesOrderEntity order = orders.byId(principal.getTenantId(), outletId, orderId)
                .orElseThrow(ResourceNotFoundException::new);
        orders.refreshOrder(order);
        String previousStatus = order.getStatus().name();
        if ("PREPARING".equals(targetStatus)) {
            order.startPreparing();
        } else if ("READY".equals(targetStatus)) {
            order.markReady();
        } else {
            order.complete();
        }
        auditLogs.persist(AuditLogEntity.recordAction(context.getTenant(), context.getOutlet(),
                references.user(principal.getUserId()), AuditLogEntity.Action.FNB_ORDER_STATUS_CHANGED,
                order.getId(), null, previousStatus + " -> " + order.getStatus().name()));
        orders.flush();
        if ("COMPLETED".equals(targetStatus)) {
            tableReconciliation.reconcile(order);
        }
        return responses(principal.getTenantId(), outletId, List.of(order)).get(0);
    }

    private List<FnbKitchenOrderResponse> responses(UUID tenantId, UUID outletId, List<SalesOrderEntity> queue) {

                .collect(Collectors.groupingBy(item -> item.getSalesOrder().getId()));
        List<UUID> itemIds = items.stream().map(OrderItemEntity::getId).toList();
        Map<UUID, List<OrderItemOptionEntity>> optionsByItem = orders.itemOptions(tenantId, outletId, itemIds).stream()
                .collect(Collectors.groupingBy(option -> option.getOrderItem().getId()));
        return queue.stream().map(order -> {
            List<OrderItemEntity> orderItems = itemsByOrder.getOrDefault(order.getId(), List.of());
            List<OrderItemOptionEntity> orderOptions = orderItems.stream()
                    .flatMap(item -> optionsByItem.getOrDefault(item.getId(), List.of()).stream()).toList();
            return FnbKitchenMapper.order(order, orderItems, orderOptions);
        }).toList();
    }

                .with("salesOrder.taxAmount")
                .with("salesOrder.serviceChargeAmount")
                .with("payment.receiptNumber")
                .with("payment.paidAt")
                .end()
                .orderByDesc("payment.paidAt")
                .orderByDesc("payment.id")
                .setFirstResult(page * size)
                .setMaxResults(size + 1)
                .getResultList();
    }

    public SummaryRow summary(UUID tenantId, UUID outletId, Instant start, Instant end,
                              OrderStatus status, PaymentMethod method) {
        return paidSalesQuery(tenantId, outletId, start, end, status, method)
                .selectNew(SummaryRow.class)
                .with("COALESCE(SUM(salesOrder.subtotal), 0)")
                .with("COALESCE(SUM(salesOrder.subtotal - salesOrder.discountAmount), 0)")
                .with("COALESCE(SUM(salesOrder.total), 0)")
                .with("COALESCE(SUM(payment.amountPaid - payment.changeAmount), 0)")
                .with("COUNT(payment.id)")
                .with("COALESCE(SUM(salesOrder.discountAmount), 0)")
                .with("COALESCE(SUM(salesOrder.taxAmount), 0)")
                .with("COALESCE(SUM(salesOrder.serviceChargeAmount), 0)")
                .end()
                .getSingleResult();
    }

    public long cancellations(UUID tenantId, UUID outletId, Instant start, Instant end) {
        return criteriaBuilderFactory.create(entityManager, SalesOrderEntity.class, "salesOrder")
                .where("salesOrder.tenant.id").eq(tenantId)
                .where("salesOrder.outlet.id").eq(outletId)
                .where("salesOrder.status").eq(OrderStatus.CANCELLED)
                .where("salesOrder.updatedAt").ge(start)
                .where("salesOrder.updatedAt").lt(end)
                .getCountQuery().getSingleResult();
    }

    public List<ProductRow> products(UUID tenantId, UUID outletId, Instant start, Instant end,
                                     OrderStatus status, PaymentMethod method, int limit) {
        CriteriaBuilder<Tuple> query = paidSalesQuery(tenantId, outletId, start, end, status, method)
                .innerJoinOn(OrderItemEntity.class, "item")
                .on("item.salesOrder.id").eqExpression("salesOrder.id")
                .on("item.tenant.id").eq(tenantId)
                .on("item.outlet.id").eq(outletId)
                .end();
        return query.selectNew(ProductRow.class)
                .with("item.product.id")
                .with("item.productNameSnapshot")
                .with("SUM(item.quantity)")
                .with("COALESCE(SUM(item.lineTotal), 0)")
                .end()
                .groupBy("item.product.id")
                .groupBy("item.productNameSnapshot")
                .orderByDesc("SUM(item.lineTotal)")
                .orderByAsc("item.productNameSnapshot")
                .setMaxResults(limit)
                .getResultList();
    }

    public List<MethodRow> methods(UUID tenantId, UUID outletId, Instant start, Instant end,
                                   OrderStatus status, PaymentMethod method) {
        return paidSalesQuery(tenantId, outletId, start, end, status, method)
                .selectNew(MethodRow.class)
                .with("payment.method")
                .with("COUNT(payment.id)")
                .with("COALESCE(SUM(salesOrder.subtotal - salesOrder.discountAmount), 0)")
                .with("COALESCE(SUM(payment.amountPaid - payment.changeAmount), 0)")
                .end()
                .groupBy("payment.method")
                .orderByAsc("payment.method")
                .getResultList();
    }

    private CriteriaBuilder<Tuple> paidSalesQuery(UUID tenantId, UUID outletId, Instant start, Instant end,
                                                   OrderStatus status, PaymentMethod method) {
        CriteriaBuilder<Tuple> query = criteriaBuilderFactory.create(entityManager, Tuple.class)
                .from(PaymentEntity.class, "payment")
                .innerJoin("payment.salesOrder", "salesOrder")
                .where("payment.tenant.id").eq(tenantId)
                .where("payment.outlet.id").eq(outletId)
                .where("salesOrder.tenant.id").eq(tenantId)
                .where("salesOrder.outlet.id").eq(outletId)
                .where("payment.paidAt").ge(start)
                .where("payment.paidAt").lt(end)
                .where("salesOrder.paymentStatus").eq(PaymentStatus.PAID)
                .where("salesOrder.status").notEq(OrderStatus.CANCELLED);
        if (status != null) {
            query.where("salesOrder.status").eq(status);
        }
        if (method != null) {
            query.where("payment.method").eq(method);
        }
        return query;
    }

    public void snapshotRates(BigDecimal taxRate, BigDecimal serviceChargeRate) {

        requireNonNegative(taxRate, "Tarif pajak tidak valid.");

    public void applyDiscount(BigDecimal amount) {
        requireNewUnpaid();
        requireNonNegative(amount, "Diskon tidak valid.");
        if (amount.compareTo(subtotal) > 0) throw new InvalidOperationException("Diskon melebihi subtotal.");
        if (taxRateSnapshot == null || serviceChargeRateSnapshot == null)
            throw new InvalidOperationException("Snapshot tarif pesanan belum tersedia.");
        discountAmount = amount;
        BigDecimal discountedSubtotal = subtotal.subtract(amount);
        taxAmount = percentage(discountedSubtotal, taxRateSnapshot);
        serviceChargeAmount = percentage(discountedSubtotal, serviceChargeRateSnapshot);
        total = discountedSubtotal.add(taxAmount).add(serviceChargeAmount);
    }

    private void requireNewUnpaid() {
        if (status != OrderStatus.NEW || paymentStatus != PaymentStatus.UNPAID)
            throw new InvalidOperationException("Perubahan hanya dapat dilakukan pada pesanan baru yang belum dibayar.");
    }

    private void requirePaidStatus(OrderStatus expected) {
        if (paymentStatus != PaymentStatus.PAID || status != expected)
            throw new InvalidOperationException("Transisi status pesanan tidak valid.");
    }

    private static void requireNonNegative(BigDecimal value, String message) {
        if (value == null || value.signum() < 0) throw new InvalidOperationException(message);
    }

    private static BigDecimal percentage(BigDecimal amount, BigDecimal rate) {
        return amount.multiply(rate).divide(new BigDecimal("100"), 2, RoundingMode.HALF_UP);
    }
